## Conventions that must not be regressed

- PES wins: a gate is ported only with a cited PES site, never because it moves
  a number toward PES.
- Constants come from the install at runtime (opcode-checked immediates or the
  referencing instruction, `PeImage::ReadVa`, VFS constant files). No PES
  number tables in code or tests.
- RNG is the PES generator and slot only (`pesrandom.hpp`,
  `Player::GetPesRandom()`), never `random()`.
- Agents work in `git worktree add --detach` worktrees, never in the main
  checkout and never in a clone.
- `tools/check_pii.sh` before every commit; stage files by name; no-reply
  identity; push after each.
