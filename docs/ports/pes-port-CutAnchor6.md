## 1. The 0x140477BC0 replay (CONFIRMED)

Two harness faults, both in `tools/dev/diffharness/snapcase.py`, found by running the replay (`run.py --snapshot-dir`, 11 s) and hooking it:

1. **"Invalid memory read ... last RIP 0x141f50ff3"** is not a PES read. `0x141F50FF3` is a 5-byte `CALL` ending 5 bytes before a page end; the harness' write hook disassembled the call with a 16-byte `mem_read(rip, 16)`, and the page after (`0x141F51000`) was not mapped yet (the block had been fetched only up to the call). The hook faulted, not PES. Fix: `_insn()` reads 16 bytes and falls back to the bytes up to the page end.
2. Then the replay ran and **one dead stack byte differed** (`0x1c75f8a0`: harness `0xF7`, translated `0x00`, twice): `0x141F5D770` (the per-cut radius helper, called from `0x141F5EC60`) executes `movzx eax, byte [rsp+0x78]` / `mov [rsp+0x20], al` on its caller's dead home slot, which in PES holds the low byte of a return address pushed by an earlier call; the translation pushes 0 there (the harness already normalised the pushed *write* to 0, not a later *read*). Fix: a non-RET read of a return-address slot reads 0 (as the translation pushed), the callee's own RET reads the real address (restored before the read), and a slot any write overwrites is data again (a first version without that last rule zeroed live data: `unmapped read at 0x18`). `retread` is still counted.
- Result: `snapdiff.py --only 0x140477BC0` over goal A's cutlist call (`goal_event_calls.py`, call from `pid2621613` seq1532 registers, seq1531 memory): **1/1 replayed, 0 mismatches, own-block 53/106 = 0.5, PROVEN**. Record: `results_core.json` (`proof: snapdiff`), `results_snapdiff_cutanchor6.json`. Layer regenerated (`gen_translated.py`: 4437 -> 4461+ functions).
- Test `tools/dev/diffharness/test_snapcase_slots.py` (ctest `translate_snapcase_slots_test`, skips 77 without `GF_DIFF_PYTHON`): 4 tests on a tiny real unicorn emulation (dead slot reads 0 and RET still returns; callee reads its own slot as 0 and RET still returns; data over a slot reads back; page-end CALL decodes).
