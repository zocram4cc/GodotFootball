## 0. Pattern found in every old turn handler (CONFIRMED by asm against the old ports)

The old group-D ports of RUN_TURN_STEP, STEP_TURN_RUN, STEP_TURN_STEP and SLIPDOWN share the defect classes the RUN_TURN_RUN re-port already found:
1. **Byte offsets read as word indices** (`[R14+4]` is `req[1]`, not `req[4]`; `[RDI+0x60]` is `req[0x18]`, `[RDI+0x80]` is `req[0x20]`). Every hidden-argument call of `FUN_14043a0a0` (the decompile prints it with no arguments) was re-read from the registers the asm loads (`callctx.py`-style dump of the 8 instructions before each CALL; scratch only).
2. **`req[8]` (the 10-way move bucket, `kMoveBucket`) used where PES reads and writes `req[0x20]` (the live bucket).** New `moveword::kLiveBucket = 0x20` in movestep.hpp.
3. **Band thresholds written as speed words**: PES stores the immediates 5.0 / 11.0 / 16.0 / 28.0 (`0x40a00000`, `0x41300000`, `0x41800000`, `0x41e00000`); the old ports stored `DAT_14259bdf4` (8.0) and friends.
4. **Row ids**: the decompile's float literals are integers: 1.87494e-42 = **0x53a** (-> 0x53b), 1.88615e-42 = **0x542** (-> 0x543), 1.85812e-42 = **0x52e** (-> 0x530), 2.38221e-44 = column **0x11**. The old port compared 0x546 / 0x54e / column 0x520.
5. **CMOVG min where the old port took the max** for the window end (`min(end, fixed frames)`); `no DAT_1425ab120 clip-length floor` outside SLIPDOWN (asm grep: 0 reads in 0x1406C3470, 0x1406C7400, 0x1406C8D80).
6. Missing calls (the run entry `vt+0`, the yaw lock `FUN_1406cbb00(P, angle)`) and `FUN_1406d2590` (TURN_STOP) called as `FUN_1406d5d60` (STOP).
