## 4. What was learned this session (for the next agent)
- The capture's object bytes cannot be overlaid over zero bytes: the ctor rows must be applied first (the vtable cells and the pointers into the object), the capture's bytes overlaid, and the route cells re-pinned to the window's VAs; the capture's +8 bytes after each vtable row are its stack garbage and the dispatches read them (`FUN_14094DAD0` reads `*(route+8)` at `0x14094DC31`).
- The tick reads `*(G+0x3B0)` (the skip object) — the window's zeroed skip record changed the flow until it was staged.
- `pes_dispatch_missing` throwing (THROW_DISPATCH) is what made this diagnosable; the generator now writes the hook, so the layer stays regenerable.
- The whole-image block lend (`.rdata`/`.data` chunks as `mem.img`) changed the tick's flow (real `.data` pointers vs zeros): do NOT lend whole blocks; the capture's H/I bytes as segments (the manifest's lines) are what the run needs.
