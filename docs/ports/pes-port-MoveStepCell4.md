## 2. The root (item 2): CONFIRMED by decompile, asm, a per-tick trace and red tests

Trace (scratch `GF_TRACE`, never committed: one line per sample of each team's `GetLoosePressMan()` while the ball rests, and per-tick MOVESTEP/command words for one man): at the first pre-BI stall H5 (id 4) sat in STEP_LOOP (4) <-> STEP_LOOP_CHANGE (5), alternating every sample, on `walk_1_1` at 4.6 to 5.2 km/h for 10 s, ~10 m from the ball. Per tick: `cmd 13.5 / 8.0 km/h` alternating (the press command's class cap flips with the instantaneous speed sample), `cls9 1`, class word 1, rate 0.05..0.25 sawtooth, `dist` falling 0.01 m a sample. At every STEP_LOOP_CHANGE the class word fell to 0 and the band word to 5 km/h, so the step loop never accelerated him past a walk. The cause is in `src/pes/movestep_step.cpp`:

- **`ClockStep(host)` returned `1 / ticksPerSecond`**, documented as "FUN_141e532d0: the logic-clock draw in [0, 1)". FUN_141e532d0 returns the frame rate **54.0** (bytes 0x42580000; docs/re/pes-re-A6Writers.md, pes-re-Dribble-inventory.md "not a draw"). Decompiles: 0x1406c4c10 line 82, 0x1406c6480 lines 136 and 148, 0x1406c6f80 line 44, 0x1406cab20 line 101 all read ground speed in km/h as `F * 60 * 60 / 1000 * |last-tick displacement|` (60.0 = 0x14259A764, 1000.0 = 0x14256AE34), so the port's ground speed was ~2,900 times too small. Every handler of the step family read a running man as standing: STEP_LOOP's slow-player re-plan (0x1406c4c10, ground < 16 km/h) always fired, and the class ladders of STEP_LOOP_CHANGE, STEP_TO_RUN and TURN_STOP always wrote band 0 with the 5 km/h word. MoveStepCell3's `PositionAt(1)` fix (metres per tick) made it visible. Fixed: `FramesPerSecond(host)` = `host.TicksPerSecond()`, the `tick` locals renamed `fps`. The other uses already followed PES's operand order (`F * dwell` at 0x1406c1070 line 22, 0x1406c6f80 line 23, 0x1406c6480 line 224; `22.5 / F`, `270 / F`, `10 / F`, `(iVar + 1) / F`) and are right now.
- **Three more decode errors in the same functions**, each read from the asm/decompile: STEP_LOOP_CHANGE (0x1406c6480) used `tick` where PES holds 0.5 (`fVar15 = DAT_142565600`, line 29) in the blended-heading integral (line 66) and in FUN_1406d2f60's threshold `(ceiling - 0.6) * 0.5` (line 126); its look-delta gate used `tick * 2` where the asm compares against 67.5 (`0x1406c6d8d COMISS XMM15,XMM3`, XMM15 = `[0x1425cca34]` = 67.5, then `0x1406c6d97 COMISS XMM3,[0x14259be60]` = 135.0); STEP_LOOP's drift word was `180 / (2 tick)` where PES loads 180.0 (`DAT_142598580`, 0x1406c4c10 line 249, or `DAT_1425ddffc` = -180.0).
- **TURN_STOP's stop block** (0x1406cb68f..0x1406cb868) compared `|displacement heading - facing|` and `|dwellLimit|` (a time standing in for an angle, which only passed because the broken clock made it 540): PES compares `|wrap180(req[1] - req[2])| < 67.5` (`[0x1425cca34]`) and `|wrap180(req[1] - req[4])| < XMM12` (= 1000.0: always true), and keeps the tick when the dwell is not over and `|wrap180(req[1] - req[4])| >= 22.5` (0x1406cb83d..0x1406cb868, `COMISS XMM8,XMM2`).
- **Inverted drift clamps**: STEP_TO_RUN (0x1406c6f80 lines 105-131) wrote the NEGATED bound for any turn inside the bound (the man turned the wrong way every tick of the blend), and RUN_TO_STEP (0x1406c1070 lines 131-147) tested `limit < delta` so its clamp never bounded anything (the root facing snapped to the heading); RUN_TO_STEP's gate also read 0.6 (0x14257a190) where PES reads 0.7 (0x14257a194).

Red tests (each red on 786a1285, green after; `build/tests/pes_movestep_step_test` 62 passed): `StepLoop.AManRunningAboveSixteenKmhIsNotReplannedAsSlow`; `StepLoopChange.{TheLastTicksGroundSpeedPicksTheBandAndItsSpeedWord, TheRunTurnStepThresholdIsHalfTheCeilingAboveTheRateFloor, TheSignTestThatEndsTheTickOnlyRunsForALookDeltaOfAtLeastSixtySevenAndAHalfDegrees}`; `StepToRun.{TheRootFacingTurnsByTheHeadingLeftOverTheRemainingDwellClampedToTheClocksReach, TheBlendedTurnIsTheStampOverTheFrameRateTimesTheFirstDwellLimit, TheStopGatesSmallErrorArmReadsTheBandFromTheGroundSpeed}`; `RunToStep.TheRootFacingTurnsTowardTheHeadingByAtMostTheClocksReachOnceTheDwellIsPastSevenTenths`. Five TURN_STOP tests whose premise was the broken clock (a displacement of 1 m a tick read as 0.07 km/h) were recalibrated to real ground speeds; `TurnStop.TheWideDisplacementTurnRunsTheClassLadder` now covers 5 / 10 / 15 km/h.
