## 1. The goal gate `0x140472640(A0, ctx, DemoInfo)` (CONFIRMED)

- Decompile (bridge) in section 2 of CutsceneTiming3 plus the callees read this session: ready byte `A0+0xEC` is set by the timer (`0x140472989`: `A0+0x14 == 0 && A0+0x131 == 0`) or by `dist(scorer man +0x55C/+0x564, T = A0+0x30) < A0+0xC - A0+0x10`; then the tail (BC in {6, 8}, `A0+0xC8 == 9`, scene != `0x300F5`) clears it again when: the scorer's anime class (`anime record +1`, tables `0x140A6E1E0` / `0x140A6E130`) is not in the accepted set, or the facing differs from the bearing to T by more than 30 deg (`[0x142591140]`, bearing `0x140439E50`), or (when the scene-flag test `0x140A7C800(DB scene table, kind 9 or 10, DemoInfo+0x10)` holds) the anime record's `+0x54` is below `[0x1425A1FFC]` = 13.5.
- **The `+1` byte and `+0x54` are the ANIME record's (`0x140A48910`, table `G+0x19C8`), not the run object's** (`G+0x21E8`). The accepted classes are read from the image table `0x1426484F0` (u32 per class, stride 4; bit 0 for `0x140A6E1E0`, mask `0x4000004` for `0x140A6E130`): **{0, 2, 3, 5, 6, 73, 74, 87, 88, 89}** (script-read). Class 10 (SHOOT), 4 (DRIBBLE), 21 (DODGE), 79 are not in it.
- Closure `closure.py --spec-set core --tag gate 0x140472640`: **237 members, 227 already in the layer, 10 new** (`0x140472640` and nine closure members incl. `0x1404B5FC0`, `0x1404B9E60`, `0x1404BA2F0`, `0x140A606C0`); set file `specgen/sets/closure-gate.txt`, 10 specs under `specs/core`.
