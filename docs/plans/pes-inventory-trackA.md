## 2. Definitions and method

- **Decoded**: Y = mechanism decoded with VAs in docs/re (open items listed in Notes); P = structure known, pieces open; D = decoded negative finding (the PES behaviour is absent); N = VA or name only.
- **Main**: F = the port on origin/main covers the decoded scope; P = partial; none = no port on main. Evidence: a source file on origin/main, its keyword content, and VA citations (`git grep` of 0x14... in src/sim and src/pes).
- **Branch-only**: code on an origin/* branch that is not an ancestor of origin/main (`git merge-base --is-ancestor`, 49 unmerged branches with band VA citations). Branches whose tips are merged are counted as main.
- **Missing**: neither decoded nor ported (N, or no doc and no port).
- **Wiring**: default = runs without `--pes-loop`; pes_loop = guarded by PesLoop() at the file:line cited; [INF] = guard not traced.
- **Weights**: count-based is primary (one row per subsystem). The code-size weighted figure in section 0 gives each row the `nodes.tsv` size of each entry VA it cites (all categories); a row citing none gets a floor, 1 KB with an 8 KB sensitivity check. The band citation shares in section 0 are over all live band function starts (live categories only). Cited bytes are a proxy for subsystem size, not a measure of it [INF].
- **VAs**: every VA in the table is cited in docs/re or docs/ports, or in origin/main src (checked for all rows). Census function-start sizes feed the section-0 weights only; they are not shown per row. Where a doc cites a constant or a mid-function address, the VA is listed as cited.
